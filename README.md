# TeksTrader

TeksTrader is a planned Android app for direct Magic: The Gathering singles trading in the Philippines.

## The Problem

Local buyers and sellers often depend on scattered group posts and private messages. Listings are difficult to search, compare, and revisit.

Store and consignment services improve convenience, but their fees can reduce value for both sides of a trade.

## The Goal

TeksTrader aims to make direct player-to-player trading fast, searchable, and practical for the local community.

The planned experience includes searchable card listings, direct buyer-seller chat, decklist imports, and workflows for common Philippine payment and delivery services.

## Status

The project is in early development. Use the GitHub issue tracker to share feedback about trading problems and feature priorities.

## Website

The public website is [tekstrader.com](https://tekstrader.com). GitHub Pages publishes its static source from `docs` on the `main` branch.
